## What’s new

- Manage repository worktrees from DROIDEX, including creation, removal, and session re-anchoring.
- Find conversations faster with session search, stable ordering, and truthful unread indicators.
- See worker and validator activity in the new subagents card and context panel.
- Get configurable finish notifications and search across Settings.
- Reopen large histories faster through the new bounded session index, watcher, transcript paging, and startup snapshot paths.

## Updating from 1.0.3

DROIDEX 1.1.0 keeps the existing application identity, user-data directory, session history, settings, and per-architecture Sparkle update feeds. Use **Check for updates** in DROIDEX, or download the DMG that matches your Mac.

The macOS artifacts are ad-hoc signed. A manual DMG install may require approval in **System Settings → Privacy & Security** on first launch.
